# Yestion 项目详细设计

## 1. 数据库设计

### 1.1 核心表结构

#### users 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| email | VARCHAR(255) | 唯一 |
| password_hash | VARCHAR(255) | bcrypt 加密 |
| name | VARCHAR(100) | 显示名 |
| avatar_url | TEXT | 头像 URL |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### workspaces 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name | VARCHAR(255) | 工作区名称 |
| icon | VARCHAR(50) | Emoji 图标 |
| owner_id | UUID | 所有者用户 ID |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### workspace_members 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| workspace_id | UUID | 工作区 ID |
| user_id | UUID | 用户 ID |
| role | ENUM | owner/admin/member/guest |
| created_at | TIMESTAMP | 创建时间 |

#### blocks 表（核心统一块表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| parent_id | UUID NULL | 父块 ID |
| workspace_id | UUID | 所属工作区 |
| type | VARCHAR(50) | 块类型 |
| properties | JSONB | 块属性 |
| content | JSONB | 子块 ID 有序数组 |
| position | INTEGER | 同级排序 |
| version | INTEGER | 乐观锁版本号 |
| created_by | UUID | 创建者 |
| updated_by | UUID | 最后更新者 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |
| deleted_at | TIMESTAMP NULL | 软删除时间 |

#### databases 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| block_id | UUID | 关联块 ID |
| name | VARCHAR(255) | 数据库名称 |
| properties_schema | JSONB | 属性定义列表 |
| views | JSONB | 视图配置 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### database_rows 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| database_id | UUID | 所属数据库 ID |
| page_id | UUID | 行页面 Block ID |
| properties | JSONB | 每行属性值 |
| position | INTEGER | 行顺序 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### comments 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| block_id | UUID | 被评论的块 |
| user_id | UUID | 评论者 |
| parent_id | UUID NULL | 父评论 ID |
| content | TEXT | 评论内容 |
| resolved | BOOLEAN | 是否已解决 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

#### revisions 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| block_id | UUID | 块 ID |
| snapshot | JSONB | 块内容快照 |
| created_by | UUID | 修改者 |
| created_at | TIMESTAMP | 快照时间 |

#### shares 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| block_id | UUID | 被分享的页面 |
| token | VARCHAR(255) | 分享令牌 |
| permission | ENUM | read/comment/edit |
| expires_at | TIMESTAMP NULL | 过期时间 |
| created_by | UUID | 创建者 |
| created_at | TIMESTAMP | 创建时间 |

## 2. API 设计

### 2.1 认证接口
- POST /api/auth/register 注册
- POST /api/auth/login 登录
- POST /api/auth/logout 登出
- GET /api/auth/me 获取当前用户
- POST /api/auth/oauth/:provider OAuth 登录

### 2.2 工作区接口
- GET /api/workspaces 我的工作区列表
- POST /api/workspaces 创建工作区
- GET /api/workspaces/:id 工作区详情
- PATCH /api/workspaces/:id 更新工作区
- DELETE /api/workspaces/:id 删除工作区
- GET /api/workspaces/:id/members 成员列表
- POST /api/workspaces/:id/members 添加成员
- PATCH /api/workspaces/:id/members/:userId 修改角色
- DELETE /api/workspaces/:id/members/:userId 移除成员

### 2.3 块与页面接口
- GET /api/blocks/:id 获取块详情
- POST /api/blocks 创建块
- PATCH /api/blocks/:id 更新块
- DELETE /api/blocks/:id 删除块
- POST /api/blocks/:id/duplicate 复制块
- POST /api/blocks/:id/move 移动块

### 2.4 数据库接口
- GET /api/databases/:id 获取数据库结构
- POST /api/databases/:id/rows 创建行
- GET /api/databases/:id/rows 查询行
- PATCH /api/databases/:id/rows/:rowId 更新行
- DELETE /api/databases/:id/rows/:rowId 删除行
- POST /api/databases/:id/views 创建视图
- PATCH /api/databases/:id/views/:viewId 更新视图

### 2.5 搜索接口
- GET /api/search?q=keyword 全局搜索

### 2.6 文件接口
- POST /api/files/upload 上传文件
- GET /api/files/:id 下载文件

### 2.7 评论接口
- GET /api/blocks/:id/comments 获取评论
- POST /api/blocks/:id/comments 添加评论
- PATCH /api/comments/:id 编辑评论
- DELETE /api/comments/:id 删除评论

### 2.8 分享接口
- POST /api/blocks/:id/shares 创建分享
- GET /api/shares/:token 获取分享内容
- DELETE /api/shares/:id 撤销分享

## 3. 前端架构

### 3.1 目录结构
前端项目采用 Next.js App Router 结构，主要目录包括 components、hooks、lib、pages 等。

### 3.2 状态管理
- 服务端数据：React Query
- UI 状态：Zustand
- 协作状态：Yjs

### 3.3 编辑器集成
- 基于 Tiptap 封装编辑器组件
- 自定义块节点
- 集成拖拽排序
- 斜杠命令菜单

## 4. 权限校验流程
1. 请求携带 JWT
2. 中间件解析用户身份
3. 查询工作区角色和页面权限
4. 检查操作权限

## 5. 实时协作设计
- 使用 y-websocket 服务器
- 房间名对应文档 ID
- 更新广播给房间内客户端
- 持久化到 Redis 和 PostgreSQL
