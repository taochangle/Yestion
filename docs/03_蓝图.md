# Yestion 系统架构蓝图

## 1. 总体架构

前端应用、API 服务层、协作服务层、数据存储层四部分构成。

前端通过 REST API 与后端通信，通过 WebSocket 与协作服务通信。

API 服务无状态可水平扩展，协作服务按房间分片。

## 2. 技术栈

| 层次 | 技术 |
|------|------|
| 前端框架 | Next.js 16 |
| 编辑器 | Tiptap 3.x |
| 协作 | Yjs |
| 状态管理 | React Query + Zustand |
| 样式 | Tailwind CSS |
| 后端框架 | Gin |
| 数据库 | PostgreSQL 16 |
| ORM | GORM |
| 缓存 | Redis 7 |
| 文件存储 | MinIO |
| 搜索 | Meilisearch |
| 部署 | Docker |

## 3. 数据流

### 页面加载
1. 浏览器请求页面
2. 前端调用 API 获取块树
3. 初始化 Yjs 文档
4. 渲染编辑器

### 编辑流程
1. 用户输入触发 Tiptap 更新
2. Yjs 生成 update
3. WebSocket 发送到协作服务
4. 广播给其他客户端
5. 异步持久化到数据库

## 4. 部署架构

- 前端部署到 CDN 或 Vercel
- API 服务多副本部署
- 协作服务独立部署
- PostgreSQL 主从复制
- Redis 集群
- 对象存储独立

## 5. 演进路线

### 阶段一：基础可用
用户认证、页面树、块编辑器、基础数据库、搜索

### 阶段二：协作增强
实时协作、评论、通知、多视图、版本历史

### 阶段三：平台化
开放 API、第三方集成、模板、离线支持
